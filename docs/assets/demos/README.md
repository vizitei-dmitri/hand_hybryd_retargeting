Ограничения и методики: основной код Hybrid — `src/dg5f_teleop/dg5f_teleop/retarget_node.py`; ViKi — `docs/knowledge` в связанном checkout `ViKi_visibility`; текущие эксперименты DexUMR — `docs/hand/FEATURE_RETARGET.md` и `RESEARCH_STRATEGY.md` в `experemental-hand`. Незакоммиченные изменения этих связанных проектов не переносятся в этот репозиторий.

`manifest.json` фиксирует исходные файлы, их SHA-256, выбранные интервалы и готовые медиаресурсы. Исходные журналы, веса и записи камер в Git не добавляются. Рендер Hybrid использует сохранённые 20 измеренных углов в порядке `rj_dg_{finger}_{joint}` и текущую `models/dg5f/dg5f_right.xml`; кадры модели получены `mj_forward`, не физической симуляцией.

Для щипка сравнены восемь фрагментов из трёх записей: проверены непрерывность трекинга, изменения углов и видимость жеста. Выбран плавный цикл с раскрытием в конце. Углы переводятся из градусов в радианы; на каждом кадре берётся последнее доступное измерение без интерполяции. Точки человека сопоставлены по времени приёма с `last_landmarks_received_monotonic_s` (максимальное расхождение 14.9 мс); это не синхронизация экспозиции. Правая панель показывает измеренное движение, а не сырые цели Hybrid. Детали выбора — в `hybrid-pinch-selection.json`.
